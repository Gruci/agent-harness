# 기능 지도

> 담는 것: 정본 그래프와 현재 소스의 자동 투영. 담지 않는 것: 사용자 승인 판정(→ components.json). 읽는 시점: 구조 변경 검토 시.

이 문서는 생성 결과이며 직접 편집하지 않는다.
컴포넌트 이름과 관계는 선언된 의도이며 이 지도 자체가 승인을 증명하지 않는다.
소스 근거는 현재 작업 파일의 해시이며 의존 관계의 실제 관측은 별도 게이트에서 검증한다.
