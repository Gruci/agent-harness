# docs/mockup/ — 화면 시안

> 담는 것: 시안을 어디에 두고 언제 치우는지. 담지 않는 것: 화면 설계 기준(→ `design/RESPONSIVE.md`)·작업 절차(→ `dev/workflows/feature-workflow.md`). 읽는 시점: 화면 시안을 만들기 전.

화면 시안은 아티팩트로 게시하지 않는다. 과업 이름의 하위 폴더에 파일로 만들어 사용자 승인을 받고, 승인된 시안 그대로 구현한다.

| 상태 | 처리 |
|---|---|
| 그 과업이 보드에 열려 있음 | 검토 중으로 본다. 종료 검사(⑯)가 막지 않는다 |
| 과업을 끝냄 | `kernel.task finish` 가 그 폴더를 과업의 archive 로 옮긴다 |
| 반려 | 지운다 |

보드에 없는 과업의 시안이 남아 있으면 종료 검사(⑯)가 막는다.
