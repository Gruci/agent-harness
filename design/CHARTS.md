# design/CHARTS.md — 차트 패턴

> 담는 것: 어떤 데이터에 어떤 차트를 쓰는지, 계열색과 축의 결정 근거. 담지 않는 것: 래퍼 시그니처(정본은 코드)·일반 색상 의미(→ `design/COLORS.md`). 읽는 시점: 새 차트를 만들기 전.

아직 차트가 없다. 차트 라이브러리를 정하고 래퍼를 만들 때 이 문서를 채운다.

## 정해야 할 것 (첫 차트 작업 시)

- [ ] 차트 라이브러리 — 고른 스택의 관례 조각(`dev/CONVENTIONS.md` 「스택 관례」)에 참고 조합이 있으면 그것부터 본다
- [ ] 래퍼 구조 — 화면 레이어(프로파일 `CHECK_PATHS["ui"]`)의 차트 래퍼 디렉토리에 타입별 래퍼(Line/Bar/Doughnut 등)를 두고, 래퍼가 공통 기본값을 자동으로 넣는다
- [ ] tooltip/legend 공통 스타일

## 규칙 (확정분)

- 모든 차트는 래퍼를 거쳐 만들고, 라이브러리로 직접 생성하지 않는다. 그래야 같은 타입의 차트가 항상 같은 모양이 된다
- 새 차트 타입을 도입하면 같은 턴에 래퍼를 추가하고 이 MD에 사용 패턴을 기록한다
