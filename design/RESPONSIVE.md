# design/RESPONSIVE.md — 반응형(웹+모바일) 정본

> 담는 것: 브레이크포인트, 데스크톱과 모바일 전환 방식, plan 반응형 설계표의 요구 형식. 담지 않는 것: 데스크톱 골격 자체(→ `design/LAYOUT.md`)·컴포넌트 내부(→ `design/COMPONENTS.md`). 읽는 시점: 화면 작업의 plan을 쓸 때, 그리고 폭이나 단위가 갈릴 때.

**원칙: 모든 화면은 설계(plan) 시점에 데스크톱·모바일 양쪽을 동등하게 정의한다.**
> 코드는 반응형으로 하나만 만들고, "모바일은 나중에 대응"은 금지다. 구현을 마친 뒤 모바일을 맞추면 리팩토링이 되지만, plan에서 두 배치를 함께 정하면 설계의 일부로 끝난다. 파일 설계표를 plan에서 쓰는 것과 같은 이유다.

## 브레이크포인트 정본

| 이름 | 범위 | 대상 |
|------|------|------|
| mobile | < 768px | 스마트폰 (기본 검증 뷰포트 390px) |
| desktop | ≥ 768px | 태블릿 가로·노트북·모니터 |

- 중간 단계(태블릿 전용) 브레이크포인트는 실제로 필요하다는 근거가 나오기 전에는 추가하지 않는다 (YAGNI).
- CSS 미디어 쿼리는 `@media (min-width: 768px)` 한 방향만 사용 — min/max 혼용 금지.
- 가능하면 브레이크포인트 없이 해결한다: `repeat(auto-fit, minmax(280px, 1fr))` · `flex-wrap` · `clamp()`.

## plan 반응형 설계표 (화면 작업 시 필수)

새로 만들거나 고치는 화면이 있는 plan.md에는 아래 표가 반드시 있어야 한다:

| 화면/컴포넌트 | 데스크톱 (≥768) | 모바일 (<768) | 전환 방식 |
|--------------|----------------|--------------|----------|
| (예) 요약 카드 4개 | 4열 | 2×2 | auto-fit minmax |
| (예) 실적 표 | 전체 컬럼 | 핵심 4컬럼 + 가로 스크롤 | 컬럼 숨김 + overflow-x |

## 강제 규칙

- **고정 px 폭 금지** — `width: NNNpx`(3자리 이상) 대신 `max-width`와 `%`/`minmax`/`clamp`를 쓴다. 불가피하면 `// px-ok: 사유` 주석을 단다. 고정 폭 검사(검사 19)가 잡으며, 판정은 ESLint에 맡긴다
- **`100vw` 금지** — 세로 스크롤바 폭만큼 가로로 넘친다. 대신 `100%`를 쓴다 (고정 폭 검사, 검사 19)
- **터치 타깃 최소 44×44px** — 버튼·탭·아이콘의 탭 영역에 적용한다. 보이는 크기가 작아도 padding으로 영역을 확보한다
- **호버 전용 인터랙션 금지** — hover로만 접근 가능한 정보(툴팁·드롭다운)는 탭/클릭으로도 열려야 한다. 터치 기기에는 hover가 없다
- **표는 모바일 전략을 반드시 고른다** — ① 핵심 컬럼만 남기고 가로 스크롤 ② 카드 리스트로 전환 중 하나다. 화면마다 plan 반응형 설계표에서 지정한다
- **차트는 컨테이너 기반 크기** — 차트 래퍼(`frontend/src/charts/`, 첫 차트 작업 시 생성)가 컨테이너 리사이즈를 처리하고, 모바일에서 legend 하단 이동·축 틱 수 축소를 기본값으로 갖는다
- **완성 검증에 모바일 포함** — 화면 완료를 선언하기 전에 390px 폭에서 가로 스크롤이 없는지와 주요 동작(필터·탭·터치)이 되는지 확인한다. 데스크톱만 보고 완료를 선언하지 않는다
