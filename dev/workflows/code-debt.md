# 의도적 부채 수확

> 담는 것: 부채 마커 수확과 원장 보고. 담지 않는 것: 단순화 선택(→ `simplicity.md`)과 과잉설계 탐지(→ `code-audit.md`). 읽는 시점: 부채 조사 또는 정비 요청 시.

## 수확

정본 주석 형식은 `../CONVENTIONS.md`를 따른다.
마커는 `debt:` 하나다.
저장소에서 주석 접두사 뒤의 마커를 검색한다.
문서가 규약을 설명하기 위해 언급한 문자열은 부채로 세지 않는다.
의존성 폴더와 버전 관리 메타데이터 및 빌드 산출물은 제외한다.
언어별 주석 문법에 맞춰 검색하고 검사한 범위를 밝힌다.

## 원장

파일별로 묶어 마커마다 한 행을 작성한다.

| 필드 | 기록할 근거 |
|---|---|
| 위치 | 파일과 줄 |
| 단순화 | 의도적으로 남긴 제약 |
| 상한 | 주석에 명시한 허용 범위 |
| 재검토 조건 | 개선을 시작할 조건이나 대안 |
| 판정 | 상한 초과, 조건 누락, 상한 누락 또는 정상 |

주석에 없는 상한이나 조건을 추측해 채우지 않는다.
현재 동작이 명시된 상한을 넘었는지는 코드와 데이터 근거로 판단한다.
상한 또는 재검토 조건이 없으면 명시적으로 표시한다.
전체 마커 수와, 상한이나 재검토 조건이 빠진 마커 수를 요약한다.
원장 파일 저장은 사용자가 요청한 경우에만 수행한다.

## 경계

읽고 보고만 하며 기존 주석이나 코드를 자동으로 수정하지 않는다.
예외로 정비를 마친 시점의 기록만 남길 수 있다.
기록 명령은 `python -X utf8 -m kernel.maintenance --stamp code-debt`다.
이 기록을 남길 수 있다고 해서 자동으로 커밋해도 된다는 뜻은 아니다.
